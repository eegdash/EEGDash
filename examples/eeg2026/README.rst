NM000134 EEG-to-image start kit
===============================

This gallery contains one real NM000134 EEG-to-image inspection tutorial:
``tutorial_eeg_to_image_start_kit.py``. It uses the BIDS EEG recording and
image-event mapping for sub-09, ses-01, task-images, run-02 to inspect signal
timing and stimulus coverage with EEGDash.

The tutorial is a local data-inspection start kit. NeuralBench owns the
official competition split, model, scoring, and submission workflow.
