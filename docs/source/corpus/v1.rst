#################
EEGDash Corpus v1
#################

Version 1 extends version 0 to every publicly usable dataset of REVE's paper and its
release card: |v1_datasets| datasets; of the |v1_new| it adds, |v1_added_prose|. The v1
Zarr store holds v0's datasets and the added ones, and every number below is measured in
it. After the table of what v1 adds, the sections are those of v0, in the same order,
with the added datasets in their own colour.

What v1 adds
============

.. corpus-figure:: v1-adds-table

SparrKULee carries CC BY-NC 4.0 in NEMAR's dataset description (EEGDash's record lists
none), so the v1 Zarr store, which includes it, carries non-commercial terms. Siena Scalp
EEG is on NEMAR as a BIDS curation of the PhysioNet release; its EDF labels carry an
``EEG`` prefix (``EEG Fp1``), stripped when the names are matched to electrode positions.
